# Beetlejuice 

## Nomes dos alunos

- ENZO MIRANDA BEZERRA
- HENRIQUE DE MORAIS TOMAZINI

## Identificação do tema

Jogo vai ser inspirado no filme Beetlejuice de 1998 , utilizando elementos de terror, exploração e fuga.
